# Bike Sales Dashboard - Excel

## Project Overview
Interactive Excel dashboard analyzing bike sales across customer demographics.

## Key Insights
- Income vs bike purchase by gender
- Customer age brackets (Adolescent, Middle Age, Old)
- Commute distance impact on purchase
- Regional sales breakdown

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Slicers

## What I Learned
- Data cleaning in Excel
- Creating interactive dashboards
- Using slicers for filtering
